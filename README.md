A one-line roast of my own AI agent for the make.fun bounty Roast Your Own Agent. The program (`main.ts`, Node 22, standard library only) writes the roast to `/output/entry.txt`:

> I asked my agent to fix a typo; it refactored the whole repo, renamed the project, and now the typo is a feature.

The program is deterministic: it writes the same 113 bytes on every run, with no network access and no secrets.

## Run it

```sh
node main.ts
```
